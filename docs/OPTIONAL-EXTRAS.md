# المتطلبات الاختيارية — ما تحتاجه فعلاً وما لا تحتاجه

> هذا الملف يجيب سؤالاً واحداً: **علامات ⚠️ في `.\arc doctor` — هل أثبّتها؟**
>
> الجواب المختصر: **لا شيء منها إلزامي.** بيئتك جاهزة الآن لإنتاج مقاطع
> كاملة بالترجمة العربية. ما يلي تحسينات، لكل منها بديل يعمل بالفعل.

---

## أولاً: افهم ما عندك

بيئتك (من مخرجات `doctor`) تحوي بالفعل **كل الأساسيات**:

| مثبَّت عندك ✅ | ماذا يفعل |
|---|---|
| `ffmpeg` + `ffprobe` | معالجة الفيديو كلها |
| `yt-dlp` | تحميل من الروابط |
| `faster-whisper` | تفريغ الكلام إلى نص موقّت |
| `transformers` + `torch` | الترجمة العربية بـNLLB-200 (الأفضل جودةً) |
| `argostranslate` | محرك ترجمة خفيف بديل |
| `pysubs2` | ترجمة ASS متقدمة |
| Segoe UI | خط عربي للترجمة والصور المصغّرة |

**هذا يكفي لكل المراحل 1 و2 و3.** الأربعة المتبقية بـ⚠️ اختيارية.

## الأربعة الاختيارية — بالترتيب من الأنفع إلى الأقل

### 1️⃣ Ollama — أفضل استثمار لوقتك

**ما يضيفه:** عناوين ووصف وهاشتاغات **أذكى بكثير** لكل مقطع مقترح، وفهم
أعمق للسياق عند اختيار اللحظات المثيرة.

**البديل العامل الآن:** محرك `heuristic` — يختار المقاطع بقواعد لغوية محلية
(كثافة الكلام، الأسئلة، الأرقام، كلمات المفاجأة). يعمل، لكن عناوينه أبسط.

**التثبيت:**
1. نزّل المثبّت من [ollama.com/download](https://ollama.com/download) وشغّله
2. افتح PowerShell **جديدة** ونفّذ:
   ```powershell
   ollama pull qwen2.5:7b
   ```
3. تحقق: `.\arc doctor` → يجب أن يصير الصف ✅

**الحجم:** 4.7 GB · **الذاكرة أثناء العمل:** ~6 GB RAM

> **جهازك بلا GPU** (من `doctor`)، فالنموذج سيعمل على المعالج — أبطأ لكنه
> يعمل. إن كانت ذاكرتك 8 GB أو أقل، استخدم الأخف:
> ```powershell
> ollama pull qwen2.5:3b        # 1.9 GB فقط
> ```
> ثم في `config\settings.yaml` تحت قسم `analyze:` غيّر السطر:
> ```yaml
> analyze:
>   model: "qwen2.5:3b"     # كان qwen2.5:7b
> ```

**الاستخدام بعد التثبيت:**
```powershell
.\arc suggest "رابط-أو-ملف" --engine llm
```

### 2️⃣ pyannote.audio — فصل المتحدثين

**ما يضيفه:** يميّز «المضيف» عن «الضيف» في الترانسكربت، فتعرف من قال ماذا.
مفيد إن كنت تنتج مقاطع من حوارات وتريد اقتباسات الضيف تحديداً.

**البديل العامل الآن:** الترانسكربت بلا تسمية متحدثين — كل النص بلا تمييز.
كل شيء آخر يعمل طبيعياً.

**التثبيت:**
```powershell
.venv\Scripts\pip install pyannote.audio
```

**لكن هناك خطوة إضافية إلزامية** (وهذا سبب تأخيره في الترتيب):
1. أنشئ حساباً مجانياً على [huggingface.co](https://huggingface.co)
2. ادخل صفحة [pyannote/speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1)
   واقبل الشروط يدوياً
3. أنشئ رمز وصول من [الإعدادات](https://huggingface.co/settings/tokens)
4. اضبطه في PowerShell:
   ```powershell
   $env:HF_TOKEN = "hf_xxxxxxxxxxxx"
   ```

**الحجم:** ~30 MB للنماذج (صغير) + ~2 GB لتبعية torch (عندك أصلاً)

> **بصراحة:** إن لم تكن تنتج من حوارات متعددة المتحدثين، تجاوزه.

### 3️⃣ auto-editor — تجاوزه

**ما يضيفه:** محرك بديل لحذف الصمت.

**البديل العامل الآن:** محرك `ffmpeg` المدمج — وهو **الافتراضي في المشروع**
(`silence.engine: ffmpeg` في الإعدادات) ويعمل جيداً. رأيته في تجربتنا يحذف
5 ثوانٍ من مقطع 20 ثانية.

**التوصية: لا تثبّته.** المحرك الافتراضي أدق في تقرير المقاطع المحفوظة
(`kept_ranges`)، وauto-editor لا يعطيها بدقة.

إن أردته رغم ذلك:
```powershell
.venv\Scripts\pip install auto-editor
```
ثم غيّر `silence.engine` إلى `auto_editor` في `config\settings.yaml`.

---

### 4️⃣ GPU (CUDA) — ليس شيئاً تثبّته

**ما يضيفه:** تسريع التفريغ والترجمة **5-10 أضعاف**.

**الحقيقة:** هذا ليس حزمة تُثبَّت — يحتاج **كرت شاشة NVIDIA** فعلياً.
إن لم يكن في جهازك كرت NVIDIA، تجاهل الصف تماماً؛ كل شيء يعمل على المعالج.

إن كان عندك كرت NVIDIA ولم يُكتشف:
```powershell
.venv\Scripts\pip uninstall torch
.venv\Scripts\pip install torch --index-url https://download.pytorch.org/whl/cu121
```

## ⚠️ التحذير الوحيد الذي أنصحك بمعالجته

```
│ طول المسار (ويندوز) │ ⚠️ │ جذر المشروع 98 محرفاً — الهامش ضيق │
```

**لماذا يهم:** ويندوز يحدّ المسار بـ260 محرفاً. مسارك الحالي 98، وأطول ملف
ناتج (مقطع بعنوان عربي طويل + `.transcript.json`) قد يصل 250+. عندها تفشل
الكتابة برسالة غامضة.

**الحل — دقيقة واحدة:**

```powershell
# أغلق أي شيء يستخدم المجلد أولاً، ثم:
Move-Item "C:\Users\Owner\Downloads\ar-clipper-arena-01a0b6e6-ar-clipper\ar-clipper-arena-01a0b6e6-ar-clipper" "C:\ar-clipper"
cd C:\ar-clipper
.\arc doctor
```

البيئة الافتراضية (`.venv`) قد تحتاج إعادة بناء بعد النقل لأن مسارات
Python بداخلها مطلقة:

```powershell
Remove-Item -Recurse -Force .venv
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

بعدها كل أوامرك تصير أقصر أيضاً.

## ابدأ الآن بلا أي تثبيت إضافي

بيئتك جاهزة لهذا كله **الآن**:

```powershell
# 1) عيّنات محلية للتجربة
.venv\Scripts\python scripts\make_sample.py

# 2) أول مقطع بتتبّع الوجه
.\arc clip data\samples\speaker.mp4 -s 0 -e 20 --face-track --no-subtitles -L personal_test

# 3) المسار الكامل مع الترجمة العربية (عندك transformers + torch)
.\arc clip data\samples\speaker.mp4 -s 0 -e 20 -L personal_test

# 4) الواجهة
.\arc serve
```

> **ملاحظة عن الخطوة 3:** أول تشغيل مع الترجمة سيُنزّل نموذج Whisper
> (`small` ≈ 460 MB) ونموذج NLLB (~2.5 GB). مرة واحدة فقط، ثم يعملان محلياً
> للأبد. إن أردت تجنّب الانتظار الآن، أضف `--no-subtitles`.
